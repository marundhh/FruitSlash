FRUIT SLASH
Mở index.html bằng trình duyệt hoặc Visual Studio Code/Visual Studio.

Cách chạy:
1. Giải nén thư mục.
2. Mở index.html.
3. Bấm BẮT ĐẦU -> chọn màn -> chọn độ khó.
4. Dùng chuột kéo để chém.

Đây là bản nền đầu tiên. Có thể chỉnh tiếp hình ảnh, âm thanh, background, skin, hiệu ứng, combo, bảng điểm và nhiều tính năng khác.


Bản cập nhật:
- Background trong màn chơi tự động đổi theme mỗi 3 phút, kèm chuyển động ánh sáng/hạt sáng.
- Thêm nhạc nền và hiệu ứng âm thanh bằng Web Audio API, không cần file audio ngoài.
- Có thể bật/tắt Nhạc nền, Hiệu ứng và chỉnh Âm lượng trong Setting; thiết lập được lưu lại.
- Do giới hạn autoplay của trình duyệt, âm thanh bắt đầu sau khi người chơi bấm BẮT ĐẦU.
